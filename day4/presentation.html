1الدرس 1 · Extension methodsDart

دوال جديدة لأنواع موجودة — بدون وراثة وبدون تعديل الأصل

  • تعمل على أي نوع: String · int · List · BuildContext — حتى لو لم نكتبه نحن.
  • تُستدعى كأنها جزء من النوع: 'ali@mail.com'.isValidEmail و 2.seconds
  • Generic: extension ListX<T> on List<T> ← getOrNull و groupBy.
  • Nullable: on String? ← nickname.orDefault()
💡 في التطبيق: كل زر ينفّذ مثالاً ويكتب النتيجة في «الكونسول» أسفل الشاشة.
extension StringX on String {
  // تحقق بسيط من البريد الإلكتروني (نستخدمه في نموذج الدرس 4)
  bool get isValidEmail =>
      RegExp(r'^[\w.+-]+@[\w-]+\.[\w.]+$').hasMatch(this);

  // تقصير النص الطويل مع …
  String truncate(int max) =>
      length <= max ? this : '${substring(0, max)}…';
}

extension DurationX on int {
  Duration get seconds => Duration(seconds: this);
  Duration get ms => Duration(milliseconds: this);
}
// await Future.delayed(2.seconds) بدل Duration(seconds: 2)

Extension types: نوع جديد «مجاني» فوق نوع موجود

  • zero-cost: لا كائن إضافي وقت التشغيل — UserId في الذاكرة مجرد int.
  • يمنع الخلط: loadUser(productId) ← خطأ ترجمة رغم أن الاثنين int.
  • implements String ← كل دوال String متاحة: email.length
  • factory مع تحقق ← لا يوجد Email غير صالح في التطبيق.
⚠️ حماية وقت الترجمة فقط: userId is int ← true. لا تعتمد عليه في is / as.
extension type UserId(int value) {
  UserId.parse(String raw) : value = int.parse(raw);
  bool get isGuest => value == 0;
}
extension type ProductId(int value) {}

String loadUser(UserId id) => 'تحميل المستخدم ${id.value}';
// loadUser(productId); ← خطأ ترجمة! رغم أن الاثنين int ✅

extension type Email._(String value) implements String {
  factory Email(String raw) {
    final v = raw.trim().toLowerCase();
    if (!v.isValidEmail) throw FormatException('بريد غير صالح', raw);
    return Email._(v);
  }
}

امتدادات BuildContext — نستخدمها في كل دروس الـ UI

  • بدل Theme.of(context).colorScheme ← context.colors
  • بدل MediaQuery.sizeOf(context) ← context.screenSize
  • بدل ScaffoldMessenger…showSnackBar ← context.showSnack('تم')
  • في الدروس 5–9: الألوان في الأنيميشن والرسم، و SnackBar عند انتهاء الحركة، ثم امتدادات جديدة: context.appColors في الدرس 8 و context.l10n في الدرس 9.
extension ContextX on BuildContext {
  ColorScheme get colors => Theme.of(this).colorScheme;
  TextTheme get textTheme => Theme.of(this).textTheme;

  // sizeOf بدل of(this).size: يُعاد البناء عند تغيّر الحجم فقط
  Size get screenSize => MediaQuery.sizeOf(this);

  void showSnack(String message, {bool error = false}) {
    ScaffoldMessenger.of(this)
      ..hideCurrentSnackBar()
      ..showSnackBar(
        SnackBar(
          content: Text(message),
          backgroundColor: error ? colors.error : null,
        ),
      );
  }
}

Unit test لمنطق السلة: group · setUp · expect

  • الكود المُختبَر: Cart في ملف الدرس — immutable: كل عملية تعيد Cart جديدة.
  • group يجمع، وsetUp يعمل قبل كل test ← حالة نظيفة دائماً.
  • AAA: Arrange (جهّز) ← Act (نفّذ) ← Assert (تحقّق).
  • Matchers: closeTo throwsArgumentError same isFalse
💡 للخطأ نمرّر دالة وليس النتيجة: () => cart.applyCoupon('FREE')
group('Cart', () {
  late Cart cart;
  // setUp: يعمل قبل كل test ← كل اختبار يبدأ من حالة نظيفة
  setUp(() => cart = const Cart());

  test('SAVE10 يخصم 10%', () {
    cart = cart.add(keyboard).add(mouse).applyCoupon(' save10 ');
    expect(cart.coupon, 'SAVE10');
    // closeTo بدل == لأن الأرقام العشرية غير دقيقة
    expect(cart.discount, closeTo(16.55, 0.001));
  });

  test('كوبون غير معروف يرمي ArgumentError', () {
    expect(() => cart.applyCoupon('FREE'), throwsArgumentError);
  });

mocktail: نستبدل الـ API بـ Mock ونتحكم بالرد

  • Mock = class فارغة ترث Mock وتطبّق الواجهة — بدون توليد كود.
  • when(…).thenAnswer للـ Future، و thenThrow لمحاكاة خطأ الشبكة.
  • verify(…).called(1) كم مرة نُوديت؟ و verifyNever لم تُستدعَ أبداً.
  • الـ Repository يأخذ ProductApi عبر الـ constructor ← نحقن الـ Mock بسهولة.
class MockProductApi extends Mock implements ProductApi {}

setUp(() {
  api = MockProductApi();
  repo = ProductRepository(api); // نحقن الـ Mock عبر الـ constructor
});

test('الكاش: نداءان للـ Repository = طلب واحد للـ API', () async {
  when(() => api.fetchProducts()).thenAnswer((_) async => []);
  await repo.getProducts();
  await repo.getProducts();
  // verify: نتحقق كم مرة نُوديت الدالة
  verify(() => api.fetchProducts()).called(1);
});

void paint(Canvas canvas, Size size) {
  const stroke = 14.0;
  final center = size.center(Offset.zero);
  final radius = (size.shortestSide - stroke) / 2;
  final rect = Rect.fromCircle(center: center, radius: radius);
  canvas.drawCircle(center, radius, track);
  // القوس: يبدأ من الأعلى (-90°) ويمتد بنسبة progress من 360°
  canvas.drawArc(rect, -math.pi / 2, 2 * math.pi * progress, false, arc);
}

@override
bool shouldRepaint(ProgressRingPainter old) =>
    old.progress != progress ||
    old.color != color ||
    old.trackColor != trackColor;
